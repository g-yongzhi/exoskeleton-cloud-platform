# Exoskeleton Cloud Platform

> 灵壳外骨骼云平台 V1.0 项目资料恢复整理版。

## 项目说明

本仓库根据现存的《灵壳外骨骼云平台 V1.0 源代码》PDF 进行整理。原始完整工程目录和可运行后端源码目前未完整留存，因此本仓库先恢复为静态前端演示项目，用于归档当时的平台页面结构、功能模块和交互思路。

当前版本不代表真实外骨骼硬件已经完整接入云平台。页面中的设备状态、步数、摔倒事件、报告数据均为演示数据。

## 已整理页面

- `index.html`：平台首页 / 数据看板
- `device.html`：设备管理
- `health-charts.html`：健康图表
- `health-report.html`：健康报告
- `family-sharing.html`：家属共享
- `setting.html`：个人设置

## PDF 中可确认的功能线索

从现存源码 PDF 中可见，该平台曾包含以下前端模块：

- 首页看板与设备状态展示
- 步数、活动时间、摔倒次数等健康数据
- 设备列表、设备详情、设备模式切换、设备绑定
- 家属授权、手机号邀请、二维码邀请
- 健康报告生成与下载
- 用户设置、本地存储、退出登录
- WebSocket 数据刷新逻辑

## 当前恢复范围

本仓库当前恢复的是可直接打开的静态前端页面：

- 保留平台主要页面和导航结构
- 使用静态演示数据模拟页面展示
- 保留设备管理、健康图表、报告、家属共享、设置等核心模块
- 不包含真实后端接口、数据库、设备通信服务
- 不包含真实外骨骼硬件接入代码
